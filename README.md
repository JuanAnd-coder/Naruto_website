# 🍥 Proyecto Web - Universo Naruto

Un sitio web interactivo e informativo dedicado al universo del anime y manga **Naruto**. Este proyecto incluye secciones detalladas sobre personajes, galería multimedia, artículos y formulario de contacto.

---

Puedes ver la página web desplegada en el siguiente enlace:  
👉 [Ver Sitio Web de Naruto](https://TU_USUARIO.github.io/naruto-website/) *(Reemplaza con tu enlace de GitHub Pages)*

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilos personalizados, diseño adaptativo (Responsive Design) y maquetación.
* **JavaScript:** Interactividad y dinámicas en el sitio.
* **FontAwesome:** Iconografía vectorial para menús e interfaz.

---

## 📁 Estructura del Proyecto

```text
sitio-web/
├── css/              # Archivos de hojas de estilo
├── fontawesome/      # Librería de iconos
├── img/              # Imágenes e ilustraciones del sitio
├── js/               # Archivos de script JavaScript
├── articulo.html     # Sección de artículos e historias
├── contactenos.html   # Formulario de contacto
├── galeria.html      # Galería de imágenes
├── index.html        # Página principal
